## Context

审查确认200个现有候选文件，没有真实凭据疑点；三处密码字面量来自测试。七处当前文档链接指向被忽略的数据库/认证记录、验收资料或部署步骤。Git索引只含.gitignore与旧README，而工作区包含完整业务实现和19项归档。

## Goals / Non-Goals

**Goals:** 新克隆能找到通用运行前置说明；公开文档引用可用；完整成果进入可复核索引；本机部署和凭据保持隔离。

**Non-Goals:** 不修改应用行为、历史SQL或.gitignore，不执行实际初始化、迁移、账号创建、部署、提交或推送。允许清理暂存差异检查准确列出的多余文件尾空行。

## Decisions

### 公开说明与本机记录分离

新增apps/api/DATABASE_SETUP.md和AUTH_CONFIGURATION.md，提取通用角色、现有CLI参数、libpq安全凭据输入及Settings环境变量说明。相比取消忽略本机文档，这样保持用户要求的部署资料隔离，并消除对历史操作记录的依赖。

公开示例使用本机回环地址与通用5432示例端口，说明须替换为目标实例。命令通过现有虚拟环境的--help和源码核对，不执行连接。生产说明只写通用前提，具体发布接入仍仅本地管理。

### 引用和过时文字

数据库/认证链接指向新文件；验收链接改为短摘要并注明附件仅本地；部署链接改为本地维护说明。维护卡修正主openspec允许Git管理、local-deployment被忽略的事实。项目概览不再用固定变更数量描述当前状态，避免新增change使其过时。

### 暂存顺序

先写完并验证文档和OpenSpec，将任务标记完成后执行限定路径的git add：.gitignore、README.md、PROJECT_OVERVIEW.md、MAINTENANCE.md、apps、openspec。该命令会记录旧OpenSpec路径删除和归档新增，不强制包含被忽略文件。随后从索引读取全部公开文档，验证链接目标实际存在于索引；复核全部索引文本中的凭据模式、超大文件及禁止目录。若验证失败，保留可审查内容并报告，不自动提交。

## Risks / Trade-offs

- [通用文档错误描述CLI] → --help及源码核对；初始化/迁移/首次管理员保持显式执行。
- [公开说明带入实际凭据] → 不复制本机完整连接串、密钥路径或服务器端点，暂存blob再次扫描。
- [只修工作区而索引仍旧] → 索引链接检查、工作区与暂存一致性检查，并确认没有剩余候选文件。

## Validation Plan

公开Markdown链接逐项验证；检查三个CLI帮助与实际环境变量行为；OpenSpec严格验证；git diff --cached --check；索引文件范围、体积与敏感模式扫描。文档变更不复跑应用测试，也不安装依赖。

首次完整暂存发现此前未跟踪文件的EOF空行：按git差异检查返回的具体路径，仅删除末尾多余换行；逐文件确认去除末尾换行后的内容完全一致。此格式修正不重写SQL或业务逻辑。
