## Context

文案分散在 App、Common 和 features 中，示例来自 lib/demo.ts。现有页头是字体星芒，favicon 是绿色星芒；纸墨主题已有紫色令牌。此变更跨多个界面但不涉及业务协议。

## Goals / Non-Goals

目标是减少常驻文案并保持操作可理解。不重新命名项目、不改变纸墨主题、不编辑用户内容或后端默认值。

## Decisions

- PageHeading 的 description 改为可选，仅有实际说明时渲染段落；移除 kicker，避免空占位。宣传侧栏块直接删去，不用新口号替换。
- 品牌使用公开 SVG 的双层卡片和短横线，页头直接引用同一 favicon 文件，避免字体差异和两份图形漂移。观点笔图标加入既有 Icon；业务关联保持链环。
- 页脚仅留 SelfLore；个人简介为空时不渲染段落。游客横幅保留“演示空间 · 只读”以维持明确标识，说明缩为“内容与统计均为示例。”按钮使用“登录 / 注册”避免与现有登录按钮产生重名。
- 三张观点保留 ID 与两组引用，换为解释概念、读书后复述和暂缓购买的具体记录；资料换成一周借阅示例表，明确为虚构数据、无真实作者归属。合集及个人示例同步精简。
- 更新已有测试中的旧显示文字，不放宽游客请求边界和身份关联断言。沿用单元测试、lint、build及游客浏览器回归并交付桌面和手机截图。

## Risks / Trade-offs

- 删除说明后页面可能过于空旷 → 对照桌面／手机渲染并整理对应标题和页头间距。
- 示例改名造成测试或关联断裂 → 保留稳定 ID、类型、顺序与引用，更新既有断言并复验。
- 简化认证提示丢失权限信息 → 保留只读、示例及登录要求，复验认证门禁。

## Migration Plan

仅前端文件更新，无迁移。用户另行要求发布时使用原发布流程；回退可恢复该批前端文件。既有未提交归档不纳入本变更。
