## Context

视觉验收确认网格、导航和半透明面板方向正确，但标题尺度与正文定位存在冲突。

## Goals / Non-Goals

**Goals:** 以 CSS 响应式排版建立稳定的标题、正文和面板间距。

**Non-Goals:** 不改变品牌、主题、导航项或内容模型。

## Decisions

采用标题最大宽度、受控 `clamp()` 字号、常规文档流的说明文字与面板内限制行宽；移除依赖绝对或视觉碰撞的排版效果。

## Risks / Trade-offs

- [标题缩小削弱戏剧性] → 保留大尺寸上限，但优先可读性。
