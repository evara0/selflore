## Context

现有 project-overview 规格要求说明随仓库交付且链接有效。实际源码已是卡片／备忘／合集／我的四入口，数据库迁移至0006，演示站点已部署。公开说明分散于根目录、API 子目录；docs、deploy 被整体忽略，不能把其中资料当作克隆前提。

## Goals / Non-Goals

**Goals:** 根 README 让首次访客按“是什么 → 在线体验 → 功能 → 本地运行 → 目录与详细说明”理解仓库；审查报告区分已观察问题和建议，保留证据。

**Non-Goals:** 不批量修复其他文档、不重构代码、不搬移文件、不新增 CI／许可证、不发布或提交。

## Decisions

- README 只保留入口级说明，不复制迁移账本、API 表格、历史测试数量或生产发布日志。
- 演示地址取自实际部署配置，仅公开 HTTPS URL；通过只读 HTTP 核对页面及前后端版本，不公开配置文件或运维凭据。
- 启动示例使用仓库根相对路径，明确 Windows 固定启动、数据库前置初始化与6171／5432示例差异，通用运行链接至随仓库交付的说明。
- 审查范围以 git ls-files 为准，另对比本机目录，避免将忽略缓存误报为 GitHub 目录杂乱。代码结构优先指出命名与职责问题，不因目录少就建议拆分工程。
- 完整审查记录放入本变更，不放到整体被忽略的 docs 目录。整理建议按优先级列出单一信息来源和未来目录草案。

## Risks / Trade-offs

- [其他文档仍含旧结论] → 根 README 使用当前事实，审查报告逐项标注待整理文档，不宣称全仓已修复。
- [只读检查不能证明新环境可运行] → 仅核对命令与入口，不安装依赖或写入业务数据库，明确未实际演练首次安装。
