## Context

桌面页脚保留 SelfLore，手机隐藏页脚而页头账号区域仍可见。已有 SVG 图标及紫色纸墨令牌可复用。

## Goals / Non-Goals

提供轻量的构建者链接，保持主导航和手机中央新建入口。不给构建者添加未经提供的姓名或简介。

## Decisions

- 共用 BuilderLinks 组件输出两个外链；桌面品牌与构建者组组成左侧区域，中间主导航、右侧新建和账号。用细竖线和间距隔开品牌与构建者；手机页头两行，第一行品牌及登录后的账号，第二行在品牌下方显示双图标及其下方署名。页脚仍在手机隐藏。
- GitHub 使用可识别的猫形 SVG，博客使用小写 b 字母 SVG；与纸墨主题保持同色，图形不依赖远程资源。
- 新标签页打开，设置 noopener noreferrer；每个图标有明确可访问名称及 title，告知新标签页行为。
- 悬停／键盘焦点执行短暂抬升和摆动，触控按压缩放；无无限循环动画。减少动态效果时禁用变换、动画和过渡。

## Risks / Trade-offs

- 320 像素页头拥挤 → 控制间距并验证 320、390、736、1024、1440 宽度。
- 仅图标难以理解 → 加可访问名称、浏览器提示及桌面构建者标签。

- 页头和 favicon 共用八向发散线条 SVG，保留当前紫墨色和纸底，恢复原标志形态。游客仅保留演示横幅的登录／注册，账号入口只在有会话时渲染，不改变认证逻辑。
