## Why

用户希望将外部整理的 JSON 直接创建为对应类别的卡片，例如将三列表格创建为清单。当前只有表单编辑和 JSON 创建 API，没有全局文件／文本导入入口；用户不应先选择卡片类别再寻找导入操作。

## What Changes

- 全局新建流程提供“手动新建／JSON 导入”两个入口，导入使用独立路由，不放在某一类卡片编辑器里。
- 支持选择 UTF-8 JSON 文件或粘贴 JSON；首版一份对象创建一张卡片，通过 kind、form、memo_format 自动识别六种类型／形式。
- 新增无持久化的预览校验 API，复用现有内容规则，为省略 ID 的清单条目生成 UUID，拒绝无效结构和未知字段。
- 预览标题、正文、问答或清单各列，以及来源等附加内容；明确确认后复用创建卡片 API，失败保留输入并支持幂等重试。
- 提供完整三字段清单示例及格式说明，完成接口、前端交互和三个宽度的浏览器验收。

## Capabilities

### New Capabilities

- `json-card-import`：全局单卡 JSON 导入、预览、校验及确认保存。

### Modified Capabilities

无。

## Impact

涉及全局新建路由与模式导航、新导入页面、API 校验服务、测试、示例与公开说明。复用既有账号权限、创建事务及幂等逻辑，无数据库迁移。不实现批量导入、导出恢复、自动创建标签或跨账号附件迁移，不自动提交、归档或发布。
