## Why

需要一个独立的前端布局基线，为后续页面与功能提供可运行的视觉外壳。

## What Changes

- 在 `apps/web/` 建立 Vite、pnpm、TypeScript 与 CSS 前端项目。
- 提供自定义 SelfLore 名称与图标、网格背景、顶端导航及半透明内容面板。
- 提供可切换的占位导航页面和固定开发端口 `24567`。

## Capabilities

### New Capabilities

- `web-layout-shell`: 可运行的前端视觉与导航布局框架。

### Modified Capabilities

- 无。

## Impact

新增前端项目、依赖、样式和布局组件；不实现业务内容、主题切换或 API 集成。
