# 默认纸墨主题实施验收

日期：2026-10-14。变更：`rebuild-default-letterpress-theme`。

## Implementation

- 默认纸张主题已覆盖四主页面、详情与关联卡片、合集封面及翻阅、复习、编辑、认证、设置、管理和回收站。
- 固定 FNV-1a 映射以原卡 ID 选择紫、蓝、绿、赭橙，排序、标题和展示位置不参与映射；合集已有封面值保持兼容。
- 标签、正文、来源、答案、边框和图标沿用卡片墨色；用户媒体保留原色。详情采用主卡片与关联侧栏，手机保留既有五入口固定底栏。
- 绿墨调整为 `#476a37`、赭橙为 `#985020`，次级文字为 `#6d6252`，用于满足纸底和淡墨底的文字对比度；其余遵循确认稿。
- 未修改 API、数据库迁移、运行配置、依赖清单、锁文件或已确认参考图；实施验收阶段尚未发布或归档；本记录随变更归档保留。

## Validation

| 检查 | 结果 |
| --- | --- |
| `pnpm test` | 6 个文件、57 项测试通过，含固定身份映射与合集兼容测试 |
| `pnpm lint` | 通过 |
| `pnpm build` | TypeScript 与 Vite 构建通过 |
| `pnpm test:e2e` | 14 项浏览器回归通过 |
| 新增真实身份断言的工作区复验 | 详情、合集与复习使用相同原卡墨色；实际评分流程通过，保存真实复习截图 |
| 主题专项 | 四种卡片的正文／标签对比度至少 4.5:1，搜索控件边界至少 3:1；排序与跨场景配色一致 |
| 响应式 | 320、390、736、1024、1440 宽度：四主页面、详情、编辑、合集编辑、设置、管理、回收站与复习无页面级横向溢出 |
| 内容及状态 | 长标题、多标签、长链接、代码、彩色多图与原图、保存失败保留输入、键盘焦点、减少动态效果、游客只读均通过 |
| OpenSpec | `openspec validate rebuild-default-letterpress-theme --strict` 通过 |

浏览器验证使用一次性 PostgreSQL `6179` 和 API `24568`，数据目录位于项目 `.cache/card-tests/letterpress-theme-20261014`。真实账号的保存、图片上传、合集、评分、改稿冲突及缓存隔离只在该环境执行。主题边界场景使用实际 React 页面及显式模拟 API，未替换应用实现。日常／生产数据库未用于验收。

本机沙盒对 Windows 原生路径解析存在限制，OpenSpec、构建和浏览器检查在获准后于沙盒外执行。运行器提示 `minimumReleaseAge` 配置与现有依赖安装记录不同；本轮使用临时的仅提示设置执行已安装脚本，没有重新安装依赖。
