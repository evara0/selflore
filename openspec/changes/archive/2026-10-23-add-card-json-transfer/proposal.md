## Why

现有卡片接口支持单张 JSON 创建和详情读取，但没有供 AI 生成内容的版本化交换规范，也不能把账号中的卡片和图片完整导出后重新导入。需要可校验、可预览、可重试的批量导入导出，避免正文、关联与附件在备份和迁移时丢失。

## What Changes

- 提供 v1 JSON Schema、中文字段说明、四类卡片示例及 AI 生成提示词，使用文件内引用键，无需 AI 编造数据库 UUID。
- 支持 JSON 批量预检与原子导入，展示字段级错误，创建新卡片并重映射标签、引用及清单条目；重试不重复创建，不覆盖已有内容。
- 支持本人完整卡片内容导出，保留来源、标签、收藏、生命周期、清单状态及关联；图片使用含 JSON 清单和原图的 ZIP 可迁移包。
- 在个人页面提供导入、预检、确认和导出入口；导出包含全类型和全生命周期，明确数据范围与数量。
- 定义卡片内容备份边界：不含账号凭据、个人资料、合集结构、活动日志及复习历史／调度状态；导入知识卡生成新的复习状态。全站灾备继续使用既有数据库与媒体备份。

## Capabilities

### New Capabilities
- `card-json-transfer`: 版本化交换格式、AI 使用规范、批量预检与导入、完整内容导出、图片包迁移及用户交互。

### Modified Capabilities
无。复用既有卡片、标签、附件及权限约束，不改变现有单卡接口与编辑语义。

## Impact

- 后端新增交换 DTO、校验／转换服务、鉴权路由及导入批次幂等记录迁移；现有 cards、memos、tags、attachments 服务需复用或抽取无提交的内部操作。
- 前端个人页与请求层新增数据交换操作，覆盖错误、长文件名、处理中和重试状态。
- 新增公开交换格式文档、Schema、示例、集成往返测试及浏览器视觉证据。
- 原工作区未提交修改不纳入本 worktree；在本worktree实施，不发布、不归档。
